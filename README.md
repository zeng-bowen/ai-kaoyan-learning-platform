# 经研｜经济学考研学习平台

第一版本地开发切片。产品范围与长期规则以 [PRODUCT_CONTEXT.md](PRODUCT_CONTEXT.md) 为准。

后续开发采用 [GitHub Flow 协作约定](CONTRIBUTING.md)：从 `main` 创建短期分支，通过 Pull Request 检查和合并。

## 已实现

- React + TypeScript 用户端九模块三栏工作台和目标院校切换；
- FastAPI + SQLite 本地数据服务；
- 知识点与练习题浏览、作答、参考答案、自评、持久保存和统计回流；
- 独立的管理员工作台：“院校与考试”只维护院校、考试科目代码及名称、备注三个字段的考试标签；知识目录和题目中心按标签关联、筛选、编辑与人工审核发布；
- 同一数据库双向同步：用户端只读已发布内容，管理员端查看近 30 秒活跃做题会话、做题总量与按难度自评表现；本地页面约每 2 秒检查一次变更；
- 题目截图批量上传与原图查看、人工录题，国产模型识别适配层与批量接口已预留；
- 旧数据库可增量升级并保留学习记录；
- 真题、兄弟院校、AI 和论坛的状态页。

当前三个考试标签、三个知识点及三道题均为**演示样本**。专业课配置尚未核验，演示题不是院校真题。考研届次由系统按中国当前公历年份加一自动计算；标签备注不是官方择校信息。试卷和题目截图统一在题目中心上传；真题和知识点内容仍需人工核验来源并审核后发布。编辑已发布题目会重新进入草稿。按当前开发约定，管理员端暂不设置访问密钥或登录，只允许从本机访问 API；尚无正式账号、角色权限和审计，**不得直接部署到公网或共享网络**。

## 运行

需要 Python 3.12+、Node.js 20+、pnpm。

在项目根目录分别启动两个终端：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r api\requirements.txt
.\.venv\Scripts\python.exe -m uvicorn api.main:app --host 127.0.0.1 --port 8000
```

```powershell
pnpm install
pnpm run dev
```

用户端打开 `http://127.0.0.1:5173/`，管理员端独立打开 `http://127.0.0.1:5173/admin/`。管理员端当前仅供本机开发使用，打开即进入工作台，不需要密钥。启动 API 和前端时必须保持 `127.0.0.1` 监听，不要改为对局域网或公网开放。若本机开发热更新受环境权限限制，可执行 `pnpm run build` 后用 `pnpm exec vite preview --host 127.0.0.1 --port 5173` 预览构建结果。

数据保存在 `data/platform.db`，截图保存在 `data/question-intakes/`，再次启动不会清空。API 文档位于 `http://127.0.0.1:8000/docs`。这些目录已被 Git 忽略。

如果从旧项目目录继续使用已有学习记录，启动 API 前将环境变量 `ECON_DB_PATH` 指向原来的 `platform.db`；不要覆盖旧文件。截图目录会自动使用该数据库所在目录下的 `question-intakes/`。

运行回归测试：`python -m unittest discover -s api -p 'test_*.py'`。

当前“实时”采用本地单机数据库与约 2 秒版本检查；在线会话按最近 30 秒做题心跳统计。主观题自评不等于正确率，因此管理员端正确率显示为空值，直到客观判分能力实现。模型未配置时，识图接口返回明确的未配置状态，不产生自动题目。后续接入模型时，在 `api/recognition.py` 实现 `RecognitionProvider`，使用 `ECON_RECOGNITION_PROVIDER=模块:工厂函数` 指向本地适配器；输出只作为管理员待审核建议。
